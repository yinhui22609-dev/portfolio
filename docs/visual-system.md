# 视觉规范 · 多页作品集

## 参考图分析

参考文件：`public/references/style.png`。它是一张静态视觉参考，不能据此确认真实网站的动画、悬停或点击行为；以下交互是基于该构图提出的实现规范。

- **字体与排版**：主视觉采用超大、宽体、粗黑无衬线拉丁字，结合倾斜、较紧字距、实心与空心描边。两个「PORTFOLIO」文字层在相近位置交叠，并通过遮挡及错位形成前后关系。顶部短句、底部姓名和职业信息明显缩小，以字号反差建立编辑排版层级。参考图不足以准确识别字体名称，不声称使用相同字体。
- **颜色**：浅灰底与黑字形成稳定底层，中央橙红色竖矩形构成唯一强烈的几何焦点。项目图片保留各自色彩，避免用全局滤镜统一原始作品。
- **空间层次**：顶部信息、中央标题、下方作品形成三个纵向节奏；标题与卡片之间保留明显呼吸空间。少量十字定位标记限定构图边界，装饰密度很低。
- **卡片构图**：下方卡片按扇形展开，左右逐步增加旋转，中间卡片更正、更靠前。卡片互相遮挡，垂直位置与投影强度不同，建立纸张般的空间深度。参考图本身使用多张设计与摄影内容；本站仅展示用户提供的五个项目原图。
- **交互方向**：将纸张空间关系延伸为可循环的圆弧作品菜单：桌面悬停选择并居中、点击进入对应项目；手机左右滑动选择。以稳定的静止感应区控制选择，不通过移动卡片自身的进入事件连续触发。

## 设计令牌

| 项目 | 值 / 原则 |
| --- | --- |
| 主背景 | `#E1E1E1` |
| 主文字 | `#111111` |
| 强调色 | `#E74735` |
| 次要文字 | 深灰，确保浅灰底上具有足够对比度 |
| 细线 | 黑色的低透明度，结构线通常为 1px |
| 基础字族 | 系统无衬线；中文优先 PingFang SC / Microsoft YaHei |
| 展示字族 | 系统粗黑无衬线，以粗字重、斜体与紧字距建立视觉特征 |
| 正文 | 至少 16px，行高约 1.6–1.8 |
| 导航 / 标签 | 14px 起；次级编号等元信息可用 12–13px |
| 间距 | 以 8px 为基础，段落与分区按信息密度扩大 |
| 圆角 | 卡片适度圆角，其余结构保持清晰直线 |
| 阴影 | 中性黑色低透明度阴影，仅用于作品卡片的层次 |

大字号通过 `clamp()` 随屏幕变化，不能将标题或整页渲染为图片。背景、红色矩形、细线和定位符号使用 CSS / SVG；所有可读文字保留为真实 HTML 文本。

## 响应式规范

- **宽桌面**：标题横向展开，红矩形在主标题后方；五卡扇形以中央为轴，左右卡片角度逐步增大。文字信息不应被卡片永久遮挡。
- **平板**：降低标题字号、卡片宽度、旋转角度和横向位移，避免依赖固定像素形成大面积溢出。
- **手机**：保留实心与描边标题及红色矩形。卡片在较紧凑的圆弧中左右滑动并吸附；保留上一项／下一项及“查看项目”入口。纵向手势和滚轮保持页面原生滚动，不得让页面本身产生横向溢出。
- **窄屏与缩放**：首页与代表性详情页已完成 320 / 390 / 768 / 1440px 宽度浏览器复查，关于页另测 320px。320px 圆弧作品区设置至少 280px 的封面高度，避免文字封面上下重叠。200% 文本缩放、真实手机触摸与跨浏览器验证尚未完成。装饰允许收敛，关键内容不可被裁切。

## 动效与可访问性

- 使用 Motion 完成首屏进入和圆弧选中动画。循环位置连续记录，项目索引按正模循环；外侧接缝设透明缓冲，避免在中央回跳。
- 桌面悬停感应区在静止位置生成快照，动画期间保持固定；命中采用稳定横向分区与逆旋转矩形轮廓，空白角落不触发选择。
- 接受至少 3px 的物理鼠标位移；候选停留 140ms 后才选择，执行前重新确认当前命中。选择锚点使用 20px 滞后阈值；返回锚点附近、离开、缩放或拖动时取消旧候选。
- 动画期间锁定悬停选择，完成后刷新感应区；仅当锁定期间发生有效物理位移时重新判断。卡片重排不通过 `mouseenter` 自动触发下一次选择。
- 鼠标滚轮保持原生页面滚动。移动端不依赖悬停，横向拖动后吸附，纵向滚动与捏合缩放保留；拖动结束产生的点击予以抑制，普通卡片链接始终指向自身项目。
- 尊重 `prefers-reduced-motion`，切换时即时定位，保留可见选中状态与操作入口。
- 所有点击入口使用原生链接或按钮；键盘 Tab 可到达，焦点样式清晰，并与悬停具有等价反馈。
- 重叠卡片不能依赖鼠标才能访问；手机端无需悬停即可理解卡片内容。
- 方向键、Home／End 操作使用稳定轨道焦点与 `aria-activedescendant`；Enter／Space 打开当前项目。上一项／下一项按钮和项目索引提供额外入口，吸附完成后播报项目名称及顺序。
- 主标题在无障碍树中只出现一次；重复描边文字与十字符号设为 `aria-hidden`。
- 图片使用准确替代文本，装饰图片使用空替代文本；原图未提供时不制造加载失败图标。
- 同时检查浅灰背景上的黑字、次要信息和橙红背景上的文字对比度；小字优先用深色。
- 不以颜色单独表达选中或可点击状态。触控目标建议至少 44px。
