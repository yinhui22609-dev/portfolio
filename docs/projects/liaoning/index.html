PROBLEM & USER TASKS

从认出一件物产，到理解它的来处。

物产内容容易停留在名称与图片展示。项目希望把自然条件、产区与地方记忆组织成档案，让地域文化兴趣用户和展陈浏览者能够查找、理解并保留感兴趣的内容。

任务定位来自设计报告与现有网页结构，不代表已完成的人群实验或使用效果验证。

查找
按自然环境、风物、生长或城地线索找到物产。
理解
连接产地、形成过程与地域关系，而不只看单品名称。
保留
把感兴趣的档案加入路线，形成可预览的分享海报。

CONTENT PRODUCT DECISIONS

让档案之间，建立可追随的联系。

用一致的档案结构承载不同物产，再用成长链、地图和收藏路径解释它们之间的关系。

用户任务 / 问题产品决策 / 取舍对应方案 / 证据
单品展示难以解释物产与自然环境之间的联系。将海岸、平原、山林与矿脉作为内容线索，以成长链和产区图谱展开关系。首页四域摄影、成长链页面与产区图谱的原始界面。
多件物产需要可检索、可比较的阅读结构。统一编号、产区、线索与操作入口；在筛选、卡片与档案详情之间保持上下文。17 件档案列表、大连海参详情，以及图谱展开状态。
浏览结束后，用户需要保留个人感兴趣的内容。把加入路线、收藏汇总、路径生成与海报预览连接成一条输出流程。已收藏 4 件物产的路线界面、初始空状态与真实海报预览图。

INFORMATION & INTERACTION MODEL

检索、理解、收藏，各有清楚的去向。

输入：自然、风物、生长与城地线索

物产探索

检索档案并查看详情

成长链

理解物产的形成过程

产区图谱

连接地点与自然环境

风物游戏

通过互动识别风物

路线生成

收藏并预览分享海报

输出：理解一件物产 / 建立地域关联 / 留下一条收藏路线

地图不是单独的装饰。

产区展开后继续呈现关联档案，让位置与物产内容互相说明。成长链补充过程视角，两者共同支撑从“在哪里”到“怎样形成”的理解。

OUTPUT & CONTINUITY

把读过的风物，连成你的辽宁。

加入路线将分散的浏览转为个人收藏。选择结果继续进入路径与海报预览，给内容阅读一个可保留的输出。
