PROBLEM & USER TASKS

先建立知识脉络，再让用户动手。

年画的意义不只在画面，也在地域、工序与传承。项目将资料分散、知识关联不清和参与感不足作为设计问题，目标是把“看作品”连接到“理解怎样制作”。

目标任务依据最终版开发汇报整理；受众定位不等同于已完成的用户验证。

初次了解
学生与年画初学者，需要快速认识题材、历史与基本工艺。
按主题查找
文化兴趣用户，需要把流派、作品、工艺和传承人联系起来。
参与体验
普通浏览者可以通过选稿、套印和盖章，直观看到制作过程。

PRODUCT DECISIONS

把科普内容，组织成可探索的路径。

用内容结构降低查找负担，用交互状态解释工艺。功能取舍围绕“找到知识、理解关系、完成一次体验”展开。

把科普内容，组织成可探索的路径。：从用户任务到产品决策与证据
用户任务 / 问题产品决策 / 取舍对应方案 / 证据
资料零散，浏览者难以串联历史、地域与技艺。按历史、流派、作品、工艺与传承人组织内容，不把所有资料堆在同一长页。最终版汇报中的内容结构，以及真实网站的主题导航、时间线与地图入口。
静态成品难以解释多次套印怎样形成画面。将体验拆成选稿、墨线版、套色与盖章；让每次动作对应可见变化。四张不同的原始状态界面，以及小游戏设计逻辑和套色印刷拆解图。
用户需要知道正在制作哪一幅、已经使用哪些色版。记录当前线稿、选中颜色与已用色版；保留步骤导航和重新体验入口。设计说明中的三个状态字段，及界面中的线稿预览、色版区与重新开始按钮。
验证与边界

已具备公开网站、原始界面与最终版汇报。尚无可核验的学习效果、任务完成率或用户反馈数据，因此不将设计目标表述为已验证成果。

INTERACTION & STATE MODEL

套色印刷，是一次可见的状态推进。

小游戏把线稿与对应色版作为输入，让选稿、刻版、套印和盖章逐步改变画面。分层图解释的是墨线与色版如何对齐成画，属于互动机制。
